# Metering-Settlement-Analysis-Dashboard


📊 About the Project

This is a Power BI project created to analyze meter information and electricity consumption.

The dashboard helps to understand:

- How many meters are gained and lost
- Meter status (Live/Lost)
- Electricity consumption
- Domestic vs Industrial meters
- Consumption by company
- Top and Bottom consuming meters

🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Excel

📁 Data Used

The project contains three main datasets:

- Meters – Meter details, status, type, company and gain/loss dates
- Meter Types – Domestic and Industrial meter information
- Consumption – Daily electricity consumption

📄 Dashboard Pages

1. Executive Overview – Main KPIs and overall trends
2. Meter & Consumption Analysis – Consumption by meter type, company and meter
3. Meter Status & Loss Analysis – Live/Lost meters and loss reasons
4. Consumption Performance – Top and Bottom consuming meters
5. Meter Details – Detailed information for a selected meter

📈 Key Insights

- 661 meters were gained and 126 meters were lost during the reporting period.
- The net meter movement was +535.
- Industrial meters had the highest share of electricity consumption.
- March 2022 had the highest number of meter losses.
- End of Contract was the main reason for meter loss.
- January 2022 had the highest monthly consumption.
